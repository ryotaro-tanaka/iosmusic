# iosmusic

iOS 音楽アプリ（Bare React Native）プロジェクトです。

## 方針

- `doc/pre-development-planning.md` に基づき、**Expo は使用しません**。
- MVP は `doc/mvp-specs/m1-1-spec.md` を起点に段階実装します。

## セットアップ

```bash
npm install
```

## 開発コマンド

```bash
# Metro
npm run start

# iOS
npm run ios

# Android
npm run android

# 型チェック
npm run typecheck

# lint（現状は型チェックを lint として運用）
npm run lint
```
