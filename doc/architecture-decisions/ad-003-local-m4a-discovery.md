# AD-003: ローカルM4A探索仕様

- ID: AD-003
- タイトル: ローカルM4A探索仕様
- 日付: 2026-02-28
- ステータス: accepted

## 背景

MVP の初期スコープは M4A 限定であり、M1-1 では「0件/複数件でも安定して一覧表示できること」がゲート条件である。探索仕様を先に固定しないと、後続の再生制御とテストが不安定になる。

## 選択肢

1. 初期から複数拡張子（m4a/mp3/aac など）を探索
2. M4A 限定・探索対象フォルダ固定
3. ユーザー指定フォルダを毎回探索

## 決定

MVP では M4A のみを対象にし、探索対象フォルダを固定する。

仕様:

- 対象拡張子は `.m4a`（大文字小文字は正規化して判定）
- 探索失敗時はクラッシュさせず、ログを残して空配列を返す
- 0件、1件、複数件の各ケースを正常系として扱う

## 採用理由

- MVP スコープ（M4A 限定）と一致し、実装・検証コストを抑えられる。
- M1-1 の DoD を明確に判定しやすい。
- フォーマット拡張は後続フェーズで互換性を保ちながら追加できる。

## 影響範囲

- ファイル探索モジュールの仕様固定。
- UI 側で「0件時の表示」を要件化する必要がある。
- 将来拡張時は本 ADR を superseded する。

## リスク / トレードオフ

- 初期ユーザーにとって対象形式が限定される。
- フォルダ固定のため、柔軟性は低い。

## 検証方法

- テストデータで 0件/1件/複数件を再現し、一覧の安定表示を確認。
- 非 M4A ファイルが混在しても誤検出しないことを確認。
- 探索失敗時にクラッシュせず空配列 + エラーログとなることを確認。
