# MVP仕様書フォルダ

このフォルダには、MVPの各マイルストーン仕様書を保存する。

## 保存ルール（推奨）

- 命名: `m<major>-<minor>-spec.md`（例: `m1-1-spec.md`）
- 1ファイル = 1マイルストーン
- 必ず以下の章立てを含める

## 推奨構成（テンプレート）

1. 目的 / スコープ
2. 非スコープ
3. ユーザーストーリー
4. 機能要件
5. 非機能要件
6. UI要件
7. データ仕様
8. 例外・エラーハンドリング
9. DoD（Definition of Done）
10. 検証手順（手動テスト）
11. リスク / 未決事項
12. 次マイルストーンへの引き継ぎ

## 既存仕様

- `m1-1-spec.md`: 曲一覧表示（ローカルM4A検出）
- `m1-1-iphone-verification-guide.md`: M1-1 を iPhone 実機で確認するための手順書
